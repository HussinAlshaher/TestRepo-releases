# TestWebApp Releases

This public repository distributes TestWebApp release notes and deployable
packages. The application source is kept separately in a private repository.

Download a version from [Releases](https://github.com/HussinAlshaher/TestRepo-releases/releases).
Choose the attached `TestWebApp-vX.Y.Z.zip` and `.zip.sha256` files. GitHub's
automatic **Source code** archives contain this release repository's files;
they are not the deployable application.

See [UPGRADING.md](UPGRADING.md) before deploying to customer hosting.
